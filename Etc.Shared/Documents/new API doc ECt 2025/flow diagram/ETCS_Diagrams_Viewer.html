Diagram Key

  • Rectangles: Processes/Steps
  • Diamonds: Decision Points

  • Blue: Bank's ETCS
  • Green: Toll Plaza System
  • Orange: Vehicle Owner Actions
  • Purple: Financial Transactions
  • Red: Error/Failure Paths
